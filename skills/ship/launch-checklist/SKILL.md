当此skill被调用时：

> **显式调用仅**: 此skill只应在用户显式使用 `/launch-checklist` 请求时运行。不要基于上下文匹配自动调用。

1. **读取参数** 获取启动日期或 `dry-run` 模式。Dry-run模式
   生成检查清单而不创建签署条目。

2. **收集项目上下文**：
   - 读取 `CLAUDE.md` 获取技术栈、目标平台和团队结构
   - 读取 `production/milestones/` 中的最新里程碑
   - 读取 `production/releases/` 中的任何现有发布检查清单
   - 如果存在，读取 `design/live-ops/content-calendar.md` 中的内容日历

3. **扫描代码库健康状况**：
   - 统计 `TODO`, `FIXME`, `HACK` 注释及其位置
   - 检查生产代码中是否遗留任何 `console.log`, `print()`, 或调试输出
   - 检查占位资源（搜索 `placeholder`, `temp_`, `WIP_`）
   - 检查硬编码的测试/开发值（localhost、测试凭证、调试标志）

4. **生成启动检查清单**：

```markdown
# 启动检查清单: [游戏标题]
目标启动: [日期 或 试运行]
生成: [日期]

---

## 1. 代码准备

### 构建健康
- [ ] 所有目标平台的干净构建
- [ ] 零编译器警告
- [ ] 所有单元测试通过
- [ ] 所有集成测试通过
- [ ] 性能基准在目标内
- [ ] 无内存泄漏（通过扩展浸泡测试验证）
- [ ] 构建大小在平台限制内
- [ ] 构建版本在源代码控制中正确设置和标记

### 代码质量
- [ ] TODO计数: [N]（启动需要为零，或有记录的例外）
- [ ] FIXME计数: [N]（需要为零）
- [ ] HACK计数: [N]（每个必须有记录的理由）
- [ ] 生产代码中没有调试输出
- [ ] 没有硬编码的开发/测试值
- [ ] 所有功能标志设置为生产值
- [ ] 错误处理覆盖所有关键路径
- [ ] 崩溃报告已集成并验证

### 安全
- [ ] 源代码中没有暴露的API密钥或凭证
- [ ] 存档数据已加密
- [ ] 网络通信已保护（TLS/DTLS）
- [ ] 反作弊措施激活（如果多人游戏）
- [ ] 所有服务器端点的输入验证（如果多人游戏）
- [ ] 隐私政策合规性已验证

---

## 2. 内容准备

### 资源
- [ ] 所有占位艺术已替换为最终资源
- [ ] 所有占位音频已替换为最终音频
- [ ] 音频混合已最终确定并由音频总监批准
- [ ] 所有VFX已打磨并验证性能
- [ ] 没有缺失或损坏的资源引用
- [ ] 资源命名约定已强制执行

### 文本和本地化
- [ ] 所有面向玩家的文本已校对
- [ ] 没有硬编码字符串（全部外部化以进行本地化）
- [ ] 所有支持的语言已翻译并验证
- [ ] 文本适合所有语言的UI（文本适配通过完成）
- [ ] 所有支持语言的字体覆盖已验证
- [ ] 制作人员名单完整、准确且最新

### 游戏内容
- [ ] 所有关卡/地图从头到尾可玩
- [ ] 教程流程完整并经过新玩家测试
- [ ] 所有成就/奖杯已实现并测试
- [ ] 存档/加载对所有游戏状态都正确工作
- [ ] 难度设置已平衡并测试
- [ ] 结束游戏/制作人员名单序列完成

---

## 3. 质量保证

### 测试
- [ ] 完整回归测试套件通过
- [ ] 零个S1（严重）错误打开
- [ ] 零个S2（主要）错误打开（或有记录的例外）
- [ ] 浸泡测试通过（8+小时连续游戏）
- [ ] 多人压力测试通过（如果适用）
- [ ] 所有关键用户路径在每个平台上测试
- [ ] 边缘情况已测试（完整存储、无网络、暂停/恢复）

### 平台认证
- [ ] PC: Steam/Epic/GOG SDK要求已满足
- [ ] 主机: TRC/TCR/Lotcheck提交已准备
- [ ] 移动: App Store/Play Store指南合规
- [ ] 无障碍: 满足最低标准（重新映射、文本缩放、色盲）
- [ ] 年龄评级已获得（ESRB、PEGI、区域）

### 性能
- [ ] 目标FPS在最低规格硬件上达成
- [ ] 所有平台上的加载时间在预算内
- [ ] 所有平台上的内存使用在预算内
- [ ] 网络带宽在目标内（如果多人游戏）
- [ ] 关键游戏时刻没有帧卡顿

---

## 4. 商店和分发

### 商店页面
- [ ] 商店页面文案最终确定并校对
- [ ] 截图当前且为每平台分辨率
- [ ] 预告片当前且已批准
- [ ] 主艺术和胶囊图片最终确定
- [ ] 系统要求准确（PC）
- [ ] 所有区域的定价已配置
- [ ] 预购/愿望清单活动激活（如果适用）

### 法律
- [ ] EULA最终确定并由法律批准
- [ ] 隐私政策已发布并链接
- [ ] 第三方许可归属完整
- [ ] 音乐/音频许可已验证
- [ ] 商标/IP许可已确认
- [ ] GDPR/CCPA合规性已验证（数据收集、同意、删除）

---

## 5. 基础设施

### 服务器（如果多人游戏/在线）
- [ ] 生产服务器已配置并经过负载测试
- [ ] 自动扩展已配置并测试
- [ ] 数据库备份已配置
- [ ] CDN已配置用于内容分发
- [ ] DDoS保护激活
- [ ] 监控和警报已配置

### 分析和监控
- [ ] 分析管道已验证并接收数据
- [ ] 崩溃报告激活且仪表板可访问
- [ ] 服务器监控仪表板上线
- [ ] 关键指标跟踪: DAU、会话时长、留存、崩溃
- [ ] 为关键阈值配置了警报

---

## 6. 社区和营销

### 社区准备
- [ ] 社区指南已发布
- [ ] 审核团队已简报且工具准备就绪
- [ ] Discord/论坛/社交渠道已设置
- [ ] FAQ和已知问题页面已准备
- [ ] 支持电子邮件/票务系统激活

### 营销
- [ ] 启动预告片已发布
- [ ] 新闻/影响者评论密钥已分发
- [ ] 社交媒体启动帖子已安排
- [ ] 启动日博客文章/开发者更新已起草
- [ ] 启动版本的补丁说明已发布

---

## 7. 运营

### 团队准备
- [ ] 启动后前72小时的值班表已设置
- [ ] 事件响应手册已由团队审查
- [ ] 回滚计划已记录并测试
- [ ] 热修复管道已测试（可以在4小时内发布紧急修复）
- [ ] 启动问题的沟通计划（谁发布、在哪里、多快）

### 首日计划
- [ ] 首日补丁已准备（如果需要）
- [ ] 服务器解锁/上线程序已记录
- [ ] 启动监控仪表板已被所有负责人收藏
- [ ] 作战室/频道已为启动日建立

---

## 启动/不启动决策

**整体状态**: [准备就绪 / 未准备就绪 / 有条件]

### 阻塞项
[列出启动前必须解决的任何项目]

### 有条件项
[列出有记录变通方法或接受风险的项目]

### 需要签署
- [ ] 创意总监 — 内容和体验质量
- [ ] 技术总监 — 技术健康和稳定性
- [ ] QA负责人 — 质量和测试覆盖
- [ ] 制作人 — 进度和整体准备
- [ ] 发布经理 — 构建和部署准备
```

5. **将检查清单保存**到
   `production/releases/launch-checklist-[date].md`，根据需要创建目录。

6. **向用户输出摘要**：总项目数、阻塞项计数、
   有条件项计数、有不完整部分的部门，以及文件路径。

当此skill被调用时：

> **显式调用仅**: 此skill只应在用户显式使用 `/release-checklist` 请求时运行。不要基于上下文匹配自动调用。

1. **从参数读取目标平台**（`pc`、`console`、`mobile`、
   或 `all`）。如果没有指定平台，默认为 `all`。

2. **读取CLAUDE.md** 获取项目上下文、版本信息和平台
   目标。

3. **从 `production/milestones/` 读取当前里程碑**以了解
   此发布应包含哪些功能和内容。

4. **扫描代码库**以查找未解决问题：
   - 统计 `TODO` 注释
   - 统计 `FIXME` 注释
   - 统计 `HACK` 注释
   - 记录它们的位置和严重性

5. **在任何测试输出目录或CI日志中检查测试结果**（如果
   可用）。

6. **生成发布检查清单**：

```markdown
## 发布检查清单: [版本] -- [平台]
生成: [日期]

### 代码库健康
- TODO计数: [N] ([如果很多则列出前5个])
- FIXME计数: [N] ([列出所有——这些是潜在阻塞项])
- HACK计数: [N] ([列出所有——这些需要审查])

### 构建验证
- [ ] 所有目标平台的干净构建成功
- [ ] 没有编译器警告（零警告政策）
- [ ] 所有资源包含并正确加载
- [ ] 构建大小在预算内 ([目标大小])
- [ ] 构建版本号正确设置 ([版本])
- [ ] 构建从标记提交可重现

### 质量门
- [ ] 零S1（严重）错误
- [ ] 零S2（主要）错误——或有记录的例外并获得制作人批准
- [ ] 所有关键路径功能经过QA测试并签署
- [ ] 性能在预算内：
  - [ ] 最低规格硬件上达到目标FPS
  - [ ] 内存使用在预算内
  - [ ] 加载时间在预算内
  - [ ] 长时间游戏会话无内存泄漏
- [ ] 相对于之前构建无回归
- [ ] 浸泡测试通过（4+小时连续游戏）

### 内容完整
- [ ] 所有占位资源替换为最终版本
- [ ] 内容文件中的所有TODO/FIXME已解决或有记录
- [ ] 所有面向玩家的文本已校对
- [ ] 所有文本已准备好本地化（无硬编码字符串）
- [ ] 音频混合最终确定并批准
- [ ] 制作人员名单完整准确
```

7. **基于参数添加平台特定章节**：

对于 `pc`：
```markdown
### 平台要求: PC
- [ ] 最低和推荐规格已验证并记录
- [ ] 键鼠控制完全功能
- [ ] 手柄支持已测试（Xbox、PlayStation、通用）
- [ ] 分辨率缩放已测试（1080p、1440p、4K、超宽）
- [ ] 窗口化、无边框和全屏模式工作正常
- [ ] 图形设置正确保存和加载
- [ ] Steam/Epic/GOG SDK已集成并测试
- [ ] 成就功能正常
- [ ] 云存档功能正常
- [ ] Steam Deck兼容性已验证（如果目标）
```

对于 `console`：
```markdown
### 平台要求: 主机
- [ ] TRC/TCR/Lotcheck要求检查清单完成
- [ ] 平台特定手柄提示正确显示
- [ ] 暂停/恢复工作正常
- [ ] 用户切换正确处理
- [ ] 网络连接丢失优雅处理
- [ ] 存储满场景已处理
- [ ] 尊重家长控制
- [ ] 平台特定成就/奖杯集成已测试
- [ ] 第一方认证提交已准备
```

对于 `mobile`：
```markdown
### 平台要求: 移动
- [ ] 应用商店指南合规性已验证
- [ ] 所有必需设备权限已证明并记录
- [ ] 隐私政策已链接且准确
- [ ] 数据安全/营养标签已完成
- [ ] 触摸控制在多种屏幕尺寸上已测试
- [ ] 电池使用在可接受范围内
- [ ] 后台行为正确（暂停、恢复、终止）
- [ ] 推送通知权限正确处理
- [ ] 应用内购买流程已测试（如果适用）
- [ ] 应用大小在商店限制内
```

8. **添加商店和发布章节**：

```markdown
### 商店 / 分发
- [ ] 商店页面元数据完整且已校对
  - [ ] 简短描述
  - [ ] 长描述
  - [ ] 功能列表
  - [ ] 系统要求（PC）
- [ ] 截图最新且满足每平台分辨率要求
- [ ] 预告片最新
- [ ] 主艺术和胶囊图片当前
- [ ] 年龄评级已获得并配置：
  - [ ] ESRB
  - [ ] PEGI
  - [ ] 其他区域评级（如需要）
- [ ] 法律通知、EULA和隐私政策到位
- [ ] 第三方许可归属完整
- [ ] 所有区域的定价已配置

### 发布准备
- [ ] 分析 / 遥测已验证并接收数据
- [ ] 崩溃报告已配置且仪表板可访问
- [ ] 首日补丁已准备并测试（如需要）
- [ ] 前72小时的值班团队计划已设置
- [ ] 社区发布公告已起草
- [ ] 新闻/影响者密钥已准备分发
- [ ] 支持团队已了解已知问题和FAQ
- [ ] 回滚计划已记录（如果发布后找到关键问题）

### 启动/不启动: [准备就绪 / 未准备就绪]

**理由：**
[准备情况评估摘要。列出启动前必须解决的任何阻塞项。
如果未准备就绪，列出需要解决的具体项目和估算解决时间。]

**需要签署：**
- [ ] QA负责人
- [ ] 技术总监
- [ ] 制作人
- [ ] 创意总监
```

9. **将检查清单保存**到
   `production/releases/release-checklist-[version].md`，如果
   目录不存在则创建。

10. **向用户输出摘要**：检查清单项目总数、
    已知阻塞项数量（FIXME/HACK计数、已知错误）和文件路径。
